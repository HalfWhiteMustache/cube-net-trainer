# מאמן קובייה פרוסה · פזצט"א

דף לימוד ותרגול לשאלות "קובייה פרוסה" (net → cube) ממבחני תפיסה מרחבית (דפ"ר, מיוני טיס).

- `index.html` — הדף עצמו: מדריך ויזואלי לשלושת כללי הפסילה, דוגמה מודרכת, ומחולל שאלות בארבע רמות. קובץ אחד, ללא שרת.
- `cube_gen.py` — אותו מנוע בפייתון, למאגר השאלות: `python cube_gen.py --n 15 --seed 11 --out out` מפיק JSON + SVG + תצוגה מקדימה.

המנוע מקפל את הפריסה למודל תלת־ממדי, מחשב את 24 המבטים האפשריים, ומאמת שכל מסיח (ניגודים / מראה / סיבוב / זר / חזרה) נפסל בכולם.
